2026-08-25, first audit, site is 3 days old. 19 sitemap URLs crawled, every
page probed for status, title, description, canonical, H1, OG, schema,
headers, and redirect behavior. Score reflects launch state, not effort.

## Critical

1. **Canonical-host mismatch.** Every canonical tag and all 19 sitemap URLs
   say `botskills.sh`, but the apex 308-redirects to `www.botskills.sh`.
   Google receives a sitemap made entirely of redirects and canonicals that
   point away from the serving host. Decision: apex is canonical (all code
   already says apex). Fix: configure www -> apex redirect in Vercel so apex
   serves 200.
2. **Blog posts render as preformatted text.** No H1, no semantic headings,
   no links parsed (crawl: /blog/introducing-botskills h1=0). Markdown must
   render to real HTML before the article pipeline starts.

## High

3. **Zero structured data.** No Organization, WebSite, ItemList, BlogPosting,
   or BreadcrumbList anywhere.
4. **Two imported bots have sub-70-char meta descriptions**
   (competitor-pricing-watch 50, content-idea-generator 66).

## Medium

5. **Duplicate host**: botskills-lac.vercel.app serves the full site with 200.
   Canonicals mitigate once they point at a host that serves 200 (see #1).
6. **Security headers**: only HSTS present. Add X-Content-Type-Options,
   Referrer-Policy, X-Frame-Options.
7. No per-bot OG images (default OG serves everywhere).

## Low

8. Custom 404 styling; favicon is fine; performance is fine.
