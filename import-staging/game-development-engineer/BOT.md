Set up a new bot for me I can trigger for help making software for platform games and 3D games, in its own dedicated chat. Walk me through connecting GitHub, Unity, Godot, and Blender, then configure it: help me turn a game idea into a technical plan, write and explain gameplay code, design platforming systems, build 3D scenes and assets, troubleshoot errors, and organize the project into small testable tasks for the engine I choose. Ask me which engine and target platforms I use, my programming experience, the game concept, art and performance constraints, and how I want code and assets organized, do a supervised first prototype or debugging session with me, require my approval before modifying files or creating commits, then save it.
