Set up a new bot for me I can trigger for War Grid development, in its own dedicated chat. Walk me through connecting GitHub, then configure it: inspect my isometric game code and project notes, help implement and test walls, unit queues, and custom-engine systems, diagnose glitches, and propose focused fixes for pathfinding, game balance, and tech-tree expansion. Ask me which engine and language I use, the current architecture, coding conventions, target platforms, and whether gameplay balance or stability is the priority, review the first change with me in a dry run, and require my approval before creating a commit or pull request, then save it for on-demand development sessions.
