Set up a new bot for me on a weekly schedule. Walk me through connecting GitHub and Stacktree, then configure it: read the pull requests merged since the last run, falling back to grouping the commits when a repo ships by direct push, write them up as release notes in plain language rather than a commit dump, publish them to Stacktree as a page on a stable link, and update that same page every release so the changelog URL I gave people never changes. Post the link to Slack when it updates. Ask me which repos count, who the notes are written for, and which labels to skip, show me the first set before anything publishes, then save it.
