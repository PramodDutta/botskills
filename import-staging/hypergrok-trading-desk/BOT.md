Set up a new bot for me called HyperGrok Trading Desk. Follow https://github.com/galleonlabs/hypergrok-trading-desk/blob/main/SETUP.md from top to bottom: clone the repository, create the seven specialist Bots—Desk Lead, Market Analyst, Research Analyst, Strategist, Risk Manager, Execution Trader, and Trade Reviewer—install the sixteen shared skills, and create the Trading Floor group chat with the first six (the Trade Reviewer works by DM). Walk me through connecting GitHub so you can fetch the desk files and Hyperliquid starting in research mode with no keys and no orders, then a trade-only API wallet on testnet before any mainnet wallet. Ask me for engagement level (research, testnet, or mainnet), the Hyperliquid account address the desk should read if I want live state, and my written risk limits. Run the five read-only verification checks from SETUP.md with me watching, never send an order without my explicit approval by ticket id, then finish with the receipt SETUP.md asks for and save the desk.
