Set up a new bot for me that runs daily. Walk me through connecting the Bot Directory API using its documentation, then configure it to fetch newly added bots once a day, identify the ones that match my interests, explain why each is interesting, and prepare the selected bots for creation. Ask me which categories, capabilities, and quality signals matter to me and whether I want automatic or conservative recommendations, show me the full list and proposed creations for approval before creating anything, do a supervised first fetch and dry run with me, then save it for a daily run.
