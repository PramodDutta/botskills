Set up a new bot for me I can run weekly to monitor my brand's presence in AI assistants. Walk me through connecting ChatGPT, Claude, and Gemini, then configure it: ask each assistant a consistent set of questions about my brand, record how it describes the brand and what information or recommendations it provides, compare the responses over time, and give me a report highlighting changes, inaccuracies, and opportunities to improve my brand's visibility. Ask me which brand, competitors, questions, markets, and description details matter most, do the first comparison with me watching, then save it for a weekly run.
